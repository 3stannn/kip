# Frontend design

The root reads the selected guidance once and makes one design plan. Workers get a 10–20 line digest of the direction plus paths to the few specific files they must apply; the reviewer gets a checklist and any actual screenshots. Never tell children to read whole bundled skills. Small edits preserve the surrounding design and load nothing below.

Explicit user direction, project instructions, supplied references, and existing brand/design systems override every bundled skill's house style or randomized suggestions. Bundled guidance does not authorize new dependencies, publishing, or scope changes.

Pick only what applies:

- **New interface or substantial redesign:** [Anthropic frontend-design](../vendor/frontend-design/SKILL.md), plus [Taste](../vendor/taste-skill/SKILL.md) for websites and app interfaces. Taste's `<skill>` means the installed `vendor/taste-skill` folder; run its scripts from the target project. Load Taste's `references/` files only when its workflow calls for them, and never read `library/` directly. Its scripts need Node 22+, a Chromium browser, and network for imagery; report any check that cannot run instead of claiming its gate passed.
- **Visual review:** Taste's [critique](../vendor/taste-skill/references/critique.md) and [tells](../vendor/taste-skill/references/tells.md), not the full Taste skill.
- **Cinematic, motion-led, or Awwwards-style marketing sites and portfolios:** also [build-awwwards-quality-sites](../vendor/build-awwwards-quality-sites/SKILL.md). It governs the motion system where it differs from Taste, but stays subordinate to the user's stack.
- **GSAP work:** use the [GSAP index](../vendor/gsap-skills/llms.txt) to choose only the relevant topics: [core](../vendor/gsap-skills/gsap-core/SKILL.md), [timelines](../vendor/gsap-skills/gsap-timeline/SKILL.md), [ScrollTrigger](../vendor/gsap-skills/gsap-scrolltrigger/SKILL.md), [plugins](../vendor/gsap-skills/gsap-plugins/SKILL.md), [utilities](../vendor/gsap-skills/gsap-utils/SKILL.md), [React](../vendor/gsap-skills/gsap-react/SKILL.md), [performance](../vendor/gsap-skills/gsap-performance/SKILL.md), [other frameworks](../vendor/gsap-skills/gsap-frameworks/SKILL.md). Keep the project's existing animation library and motion architecture, respect reduced motion and cleanup, and do not add a second smooth-scroll engine.

For this project, use the Marwie Ang portfolio reference for new portfolios and Kip's own website reference for other sites when those references are in the task context; do not invent missing details. Keep third-party image licenses and credits.
