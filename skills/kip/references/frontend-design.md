# Frontend design

Read [Anthropic's frontend-design skill](../vendor/frontend-design/SKILL.md) for new interfaces and substantial visual redesigns. Use its subject-specific direction, typography, copy, and critique principles as shared foundations alongside the applicable guidance below. Keep one design plan rather than stacking separate workflows; the task's brief and chosen direction resolve stylistic differences between bundled skills. Small edits use only relevant principles and preserve the surrounding design.

Kip bundles [Taste's design-taste-frontend skill](../vendor/taste-skill/SKILL.md). Read it for new websites, substantial redesigns, app interfaces, and visual reviews. Its `<skill>` placeholder means the installed `vendor/taste-skill` folder relative to Kip, not the project root. Run its scripts from the target project so generated working files stay there.

For Awwwards-quality, cinematic, interactive, high-concept, or motion-led marketing sites and portfolios, also read [Meng To's build-awwwards-quality-sites skill](../vendor/build-awwwards-quality-sites/SKILL.md). Use Taste as its compatible bundled web-design companion for composition and critique. Select one coherent visual and motion direction: the Meng To guidance governs the requested motion system where it differs from Taste's defaults. Its prescribed GSAP, smooth-scroll, imagery, and icon choices remain subordinate to the user's requested stack, available tools, and existing project systems. Do not add those dependencies to routine frontend edits or app screens simply because this skill is bundled. Include the selected guidance in worker and reviewer handoffs.

Explicit user direction, project instructions, supplied references, and existing brand/design systems take precedence over Taste's randomized directions, house style, and suggested assets. Within this project, use the Marwie Ang portfolio reference for new portfolios and substantial portfolio redesigns, and the reference extracted from Kip's own website for other websites when those references are available in the task context. Do not invent missing reference details. Apply Taste's craft and critique guidance within the chosen direction. Small edits preserve the surrounding design and do not start a full design run.

Keep the requested stack, hosting workflow, publishing authorization, and Kip orchestration contract. Taste provides design guidance, not permission to publish or change the task's scope. Load only task-relevant supporting references. Give frontend workers the installed Taste path and shared design decisions; give reviewers the same constraints and any actual screenshots or inspection results.

The bundled scripts use Node.js 22+; browser inspection needs Chrome, Edge, or Chromium, and image discovery needs network access. Use the host's available browser tools when its instructions require them. If a check cannot run, report that limit and use available verification without claiming the Taste gate passed. Keep third-party image licenses and credits when using downloaded assets.

The pinned source revisions and redistribution licenses are recorded for [Anthropic's skill](../vendor/frontend-design/SOURCE.md), [Taste](../vendor/taste-skill/SOURCE.md), and [Meng To's skill](../vendor/build-awwwards-quality-sites/SOURCE.md). Kip installations and updates carry these copies without running `npx skills add` or downloading dependencies.
