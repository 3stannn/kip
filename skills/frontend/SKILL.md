# Frontend

Reuse the project framework and component patterns. Keep derived state derived and effects limited to external synchronization. Implement semantic controls, visible keyboard focus, accessible names, and predictable loading and error feedback. Validate responsive layout and long content. Use the project's icon components or SVGs for interface icons; do not use emoji or Unicode symbols as icons because platforms can substitute inconsistent emoji glyphs. Keep decorative icons out of the accessibility tree, and give meaningful icons accessible names. Keep secrets and authorization enforcement on the server. Avoid adding dependencies for simple browser capabilities. Separate rendering from transport where it improves testing and maintainability. Define the API contract before inventing mock responses.
