# Frontend Design

Use the existing product identity and real content to establish hierarchy before choosing decoration. Choose a clear type scale, spacing rhythm, and one purposeful visual direction. Avoid interchangeable hero sections, excessive cards, random gradients, and invented metrics. Adapt structure to the content rather than forcing every page into the same template. Specify mobile behavior, focus states, loading, empty, and error states. Prefer existing assets and explain any missing assets.
